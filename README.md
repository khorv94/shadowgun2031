# Shadowrun 2031

## Introduction

_Shadowrun 2031_ is a first-person shooter introducing mild cyberpunk elements to the gameplay. The game takes place in the year 2031 and is based on Shadowrun (2007)

### Factions

The player chooses between two factions: The megacorporation known as RNA Global (CT), and the resistance group known as The Lineage (T).
