# SHADOWGUN 2031

## Introduction

_Shadowgun 2031_ is a first-person shooter introducing mild cyberpunk elements to the gameplay. The game takes place in the year 2031 and is based on Shadowrun (2007)

### Factions

The player chooses between two teams. (CT) or (T).

### Races


| Race  | Pros / Cons                      |
| ----- | -------------------------------- |
| Human | Well rounded stats, +shop        |
| Elf   | Fast, squishy, silent, +magic    |
| Dwarf | Sturdy, healthy, small, +tech    |
| Troll | Tanky, slow, loud, big, +weapons |

## Shop Categories

### Magic

| Magic        | Desc                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- |
| Tree of Life | Large tree that provides cover and heals nearby allies until destroyed                      |
| Resurrect    | Revive dead teammates                                                                       |
| Smoke        | Become shrouded, invulnerable to damage, and unable to attack for a brief duration          |
| Strangle     | Create a damaging growth of crystals in an area                                             |
| Gust         | Push opponents with a forceful wind. Push humans and elves farther than dwarves and trolls. |


### Tech

| Tech      | Desc                                                                                   |
| --------- | -------------------------------------------------------------------------------------- |
| Glider    | BotW style hang glider. Pair with shotgun to attack enemies from the air               |
| Walls     | Toggle for a brief duration. Enemies hear a sound when they've been detected via walls |
| AntiMagic | EMP Pulse grenade that desecrates magic abilities such as Trees and Crystals.          |

### Weapons

### upgrade system

- Weapons can be upgraded up to 3 times. 
- Weapon gains 1 potential level each round 
- Player can spend money to upgrade weapon
- Player can purchase 1 upgrade per weapon per round (potential level allowing)
- Player cannot upgrade ak while CT and vice versa
