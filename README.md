# SHADOWGUN 2031

## Introduction

_Shadowgun 2031_ is a first-person shooter introducing mild cyberpunk elements to the gameplay. The game takes place in the year 2031 and is based on Shadowrun (2007)

### Factions

The player chooses between two teams. (CT) or (T).

### Races

#### Human
Well rounded stats, good with shop($)
#### Elf
Fast, squishy, silent, good with magic
#### Dwarf
Sturdy, small, good with tech
####
Tanky, slow, loud, big, good with weapons
